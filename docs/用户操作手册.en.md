# Wallpaper Studio User Manual

This guide covers installing and using Wallpaper Studio (`wallpaper-rs`).

<p align="center">🌐 <a href="用户操作手册.md">简体中文</a> · <a href="用户操作手册.en.md">English</a></p>

---

## 1. Install & launch

### Prebuilt (Windows)

1. Download `dist/wallpaper-rs-windows-x64.exe`.
2. Double-click to run — no install, no admin rights required.

### Build from source (all platforms)

```bash
git clone https://github.com/shuying-code/wallpaper-rs.git
cd wallpaper-rs
cargo run --release
```

Requires Rust 1.75+.

---

## 2. Layout

- **Top bar**: brand name, current-mode chip (Slideshow / Paused), and the current wallpaper filename on the right.
- **Left navigation**: Library / Slideshow / Settings / About.
- **Main area**: changes with the selected section; the status bar shows item counts and results.

---

## 3. Library (fixed wallpaper)

1. Click **Choose folder…** and pick an image directory.
2. For nested images, tick **Include subfolders** and click **Rescan**.
3. Thumbnails appear in a grid; use **Search** to filter by filename.
4. Click a thumbnail or **Set as wallpaper** to apply it immediately.
5. The current wallpaper is outlined in blue and marked **● Current**.

Supported formats: JPG / PNG / WebP / BMP / GIF / TIFF.

---

## 4. Slideshow (auto rotation)

1. **Mode**: choose **Slideshow**.
2. **Start / Pause**: press Start to rotate on the interval; press again to pause.
3. **Previous / Next**: manual switch (also `←` / `→`).
4. **Random**: switch to a random image now.
5. **Shuffle order**: rotate in random order.
6. **Interval**: drag the slider or pick a preset (10s / 30s / 1m / 5m / 15m / 30m / 1h / 6h / 1d).
7. A progress bar shows the time until the next change.

> The preview above shows a large preview of the current wallpaper.

---

## 5. Settings

- **Display mode**: Fill / Fit / Stretch / Center / Tile. Windows writes the registry desktop style; Linux applies via GNOME `picture-options`; macOS uses the OS default scaling.
- **Theme**: light / dark, applied instantly.
- **Include subfolders**: controls recursive scanning.
- **Launch at login**: run automatically when you sign in. Windows writes `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, macOS writes `~/Library/LaunchAgents`, Linux writes `~/.config/autostart`.
- **Config file**: shows the path, with **Open config folder** and **Save now**.

---

## 6. About

Shows version and feature list. `wallpaper-rs --version` prints the version;
`wallpaper-rs --selftest` runs config and image-decoder self-checks.

---

## 7. Config file

All settings are saved as JSON:

| Platform | Path |
|---|---|
| Windows | `%APPDATA%\wallpaper-rs\config.json` |
| macOS | `~/Library/Application Support/wallpaper-rs/config.json` |
| Linux | `$XDG_CONFIG_HOME/wallpaper-rs/config.json` (default `~/.config/wallpaper-rs/config.json`) |

Fields: `folder`, `recursive`, `mode`, `interval_secs`, `shuffle`, `fit`, `theme`, `last_path`, `running`, `search`.

## 9. FAQ

- **Nothing happens when setting the wallpaper?** On Windows ensure the path exists and is readable; on Linux install GNOME (`gsettings`) or `feh`; on macOS you may need to allow controlling System Events under System Settings → Privacy & Security → Automation.
- **Thumbnail shows "Loading…"?** Large images take a moment; "Cannot preview" means the file cannot be decoded.
- **Chinese text shows as boxes?** The app embeds system CJK font loading; if boxes appear, ensure a CJK font is installed.

---

## 10. Uninstall

- Windows: delete the exe; to remove settings, delete `%APPDATA%\wallpaper-rs`.
- macOS / Linux: delete the binary and the config directory above.

## 11. OLED burn-in guard

On OLED panels, static elements (taskbar, clock, icons) shown for long periods can leave ghosting or permanent burn-in. In **Settings → OLED 防烧屏**:

1. Tick **防烧屏守护**.
2. Set the **interval** (default 60s) and **max shift** (default 8 px).
3. The app periodically shifts the current wallpaper by a few random pixels and re-applies it, spreading pixel load over time.
4. Use **立即位移一次** to trigger a shift immediately.

> Pair it with slideshow rotation (e.g., every 5–15 min) for the best effect.

## 12. Full-disk scan

In the **Library** toolbar click **全盘扫描**: the app scans all drives for images in the background (skipping system/cache dirs and bounding the result), then loads them into the library. The UI stays responsive.

## 13. Resident mode & global hotkey

- **Close to background**: when enabled, closing the window keeps the app running so rotation / burn-in guard continue.
- **Global hotkey**: defaults to `Ctrl+Alt+W` to minimize / restore; if taken by another app it auto-falls back to `Ctrl+Alt+Shift+W`, etc. Settings shows the active hotkey.
- Use **最小化到后台** to hide immediately.

## 14. Display & compatibility

Settings → **显示与兼容** shows the monitor count, primary resolution and current theme. HiDPI scaling is handled by the OS; the wallpaper is applied to all monitors.
