# Wallpaper Studio User Manual

This guide covers installing and using Wallpaper Studio (`wallpaper-rs`).

<p align="center">🌐 <a href="用户操作手册.md">简体中文</a> · <a href="用户操作手册.en.md">English</a></p>

---

## 1. Install & launch

### Prebuilt (Windows)

1. Download `dist/wallpaper-rs-windows-x64.exe`.
2. Double-click to run — no install, no admin rights required.

### Build from source (all platforms)

```bash
git clone https://github.com/shuying-code/wallpaper-rs.git
cd wallpaper-rs
cargo run --release
```

Requires Rust 1.75+.

## 2. Layout

- **Top bar**: the `☰` button at the far left hides / shows the left navigation; then the brand name, current-mode chip (Slideshow / Paused), and the current wallpaper filename on the right.
- **Left navigation**: Online library / Local library / Slideshow / Daily wallpaper / Settings / About (collapsible via `☰`).
- **Main area**: changes with the selected section; the status bar shows item counts and results.

---

## 3. Local library (fixed wallpaper)

1. Click **Choose folder…** and pick an image directory.
2. For nested images, tick **Include subfolders** and click **Rescan**.
3. Thumbnails are **grouped into albums by their containing folder**: each album header has `▼ / ▶` to expand / collapse it individually; the toolbar offers **Expand all / Collapse all** and shows the album count. Albums are ordered by folder modified time, newest first.
4. Use **Search** to filter by filename (albums with no match are hidden automatically).
5. Click a thumbnail or **Set as wallpaper** to apply it immediately.
6. The current wallpaper is outlined in blue and marked **● Current**.
7. If the scan hits folders it cannot read, a banner appears at the top: **Request permission / Retry** tries again (macOS shows the system privacy prompt), **Open folder location / Open authorization settings** jumps to the file manager or the OS authorization page so you can grant access, and **Ignore** dismisses it.

Supported formats: JPG / PNG / WebP / BMP / GIF / TIFF.

## 4. Online library (multi-site)

Open the **Online library** section in the left navigation. You can switch between four real wallpaper sites at the top:

| Site | Domain | Notes |
|---|---|---|
| Microsoft Bing daily wallpaper | `bing.ioliu.cn` | 4K, updated daily; original 3840×2160 download |
| Netbian (彼岸图网) | `pic.netbian.com` | 4K / 5K / 8K HD |
| MoeWalls | `moewalls.com` | Live wallpapers (MP4) |
| MotionBGs | `motionbgs.com` | Live wallpapers (MP4) |

How to use it:

1. **Switch source**: click a site button (Bing / Netbian / MoeWalls / MotionBGs).
2. **Keyword search**: type a keyword (e.g. "landscape", "starry") and click **Search**; click **Back to categories** to return to category browsing.
3. **Browse by category / tag**: click a category chip under the toolbar (categories come from each site).
4. **Paging**: the toolbar has **‹ Prev**, **Page x / y**, **Next ›** and a **N on this page** chip; click **Refresh** to reload the current page.
5. **Preview & actions**: click a thumbnail to open the large preview, which offers:
   - **Set as desktop wallpaper** / **Set as lock screen** — downloads the original, then applies it;
   - **Download original** — saves it to `Pictures/网上壁纸库/<site>`;
   - **Download live wallpaper MP4** (live sites such as MoeWalls / MotionBGs) — saves the video to the same folder;
   - **Set as live wallpaper** (live sites such as MoeWalls / MotionBGs, Windows only) — downloads the MP4 and plays it in a window behind the desktop icons; reopening the preview shows **Stop live wallpaper**;
   - **Close preview**.
   > While the original is downloading the app shows "Downloading original — the chosen action runs when it finishes".
   > The live wallpaper relies on **mpv**: the Windows portable package, installer and single-file exe **all bundle it** (the portable package keeps it in an `mpv/` folder next to the app; the single-file exe extracts it to `%LOCALAPPDATA%\wallpaper-rs\mpv-runtime` on first use) — works out of the box. When built from source or otherwise, it is auto-detected on PATH and common install folders, or set `WALLPAPER_MPV` to your `mpv.exe`. The bundled mpv is a third-party GPL component — see `THIRD-PARTY-NOTICES.md`. It stays active while the app runs and stops when the app exits.
6. **Favorites**: click the hollow `☆` in a card corner to add it (`★` when saved). The top **☆ Favorites only (N)** chip toggles between browsing everything and favorites only; favorites can also be filtered by title. Favorites are persisted.
7. **Clear thumbnail cache**: click **Clear thumbnail cache** to free texture memory.

Note: this section needs network access to the sites; on failure it shows "Failed: …" with a **Retry** button. Source / category, search and page state are remembered and restored next time.

## 5. Slideshow (auto rotation)

1. **Mode**: choose **Slideshow**.
2. **Start / Pause**: press Start to rotate on the interval; press again to pause.
3. **Previous / Next**: manual switch (also `←` / `→`).
4. **Random**: switch to a random image now.
5. **Shuffle order**: rotate in random order.
6. **Interval**: drag the slider or pick a preset (10s / 30s / 1m / 5m / 15m / 30m / 1h / 6h / 1d).
7. A progress bar shows the time until the next change.

> The preview above shows a large preview of the current wallpaper.

## 6. Settings

- **Display mode**: Fill / Fit / Stretch / Center / Tile. Windows writes the registry desktop style; Linux applies via GNOME `picture-options`; macOS uses the OS default scaling.
- **Theme**: light / dark, applied instantly.
- **Include subfolders**: controls recursive scanning.
- **Launch at login**: run automatically when you sign in. Windows writes `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, macOS writes `~/Library/LaunchAgents`, Linux writes `~/.config/autostart`.
- **Lock screen**: also set the current wallpaper as the system lock screen. On Windows this writes `HKLM\...\PersonalizationCSP`, which needs administrator rights — clicking the button raises the system UAC prompt automatically, so just click **Yes** to finish; **no need to run the app as administrator manually**. Ubuntu / GNOME sets the lock-screen `picture-uri` via `gsettings`; macOS lock screen follows the system wallpaper.
- **Config file**: shows the path, with **Open config folder** and **Save now**.

## 8. Config file

All settings are saved as JSON:

| Platform | Path |
|---|---|
| Windows | `%APPDATA%\wallpaper-rs\config.json` |
| macOS | `~/Library/Application Support/wallpaper-rs/config.json` |
| Linux | `$XDG_CONFIG_HOME/wallpaper-rs/config.json` (default `~/.config/wallpaper-rs/config.json`) |

Fields: `folder`, `recursive`, `mode`, `interval_secs`, `shuffle`, `fit`, `theme`, `last_path`, `running`, `search`, plus the online-library state `web_source_key`, `web_category`, `web_query`, `web_search_active`, `web_only_fav`, `web_favorites`.

## 10. FAQ

- **Nothing happens when setting the wallpaper?** On Windows ensure the path exists and is readable; on Linux install GNOME (`gsettings`) or `feh`; on macOS you may need to allow controlling System Events under System Settings → Privacy & Security → Automation.
- **Thumbnail shows "Loading…"?** Large images take a moment; "Cannot preview" means the file cannot be decoded.
- **Online library fails to load?** Make sure the network can reach the site (some sites may need access outside the region); click **Retry**, or switch source / category and retry.
- **Chinese text shows as boxes?** The app embeds system CJK font loading; if boxes appear, ensure a CJK font is installed.

## 11. Uninstall

- Windows: delete the exe; to remove settings, delete `%APPDATA%\wallpaper-rs`.
- macOS / Linux: delete the binary and the config directory above.

## 12. Close to system tray (icon kept visible)

Clicking the top-right "X" does not quit by default; it hides the window to the system tray (the taskbar button disappears) while rotation and the online daily wallpaper keep running in the background:

- Windows: notification area (bottom-right).
- macOS: menu bar (top-right).
- Linux: status area / AppIndicator.

To stop Windows 11 from tucking the icon into the "Show hidden icons" overflow, the app tries at start-up to pin its tray icon as always-visible; if it still doesn't show, open **Settings → Tray & hotkey** and click **Open tray settings (show the icon permanently)** and switch it to "Show" once.

Single-click the tray icon to bring the window back; right-click for **Show / Hide / Quit wallpaper-rs**. **Quit wallpaper-rs** is a real exit: it ends the background process *and* closes every other running wallpaper-rs instance on the machine (e.g. autostart + a manual start, or the exe launched twice), so no stray rotation keeps running.

> To stop it from keeping running in the background, turn off **Hide to tray on close** under **Settings → Tray & hotkey**; the "X" then quits directly.

## 13. Full-disk scan

In the **Local library** toolbar click **全盘扫描**: the app scans all drives for images in the background (skipping system/cache dirs and bounding the result), then loads them into the local library. The UI stays responsive.

## 14. Tray & global hotkey

- **Hide to tray on close**: enabled by default; closing the window hides it to the notification area (icon kept visible) while rotation / online wallpaper keep running in the background.
- **Global hotkey**: defaults to `Ctrl+Alt+W` to show / hide the window; if taken by another app it auto-falls back to `Ctrl+Alt+Shift+W`, etc. Settings shows the active hotkey.
- You can also click **隐藏到托盘 (Hide to tray)** to hide to the tray immediately (no taskbar button), or **退出应用 (Quit)** to exit fully — Quit also closes every other running wallpaper-rs instance, so no background rotation is left behind.

## 15. Display & compatibility

Settings → **显示与兼容** shows the monitor count, primary resolution and current theme. HiDPI scaling is handled by the OS; the wallpaper is applied to all monitors.

## 16. Responsive UI & mobile (iOS / Android)

- **Redesigned UI**: a warm modern look (paper-cream background + terracotta accent + deep teal), consistent in light and dark themes.
- **Narrow / phone layout switches automatically**: below ~820pt (or on a phone/tablet) the left sidebar collapses into a **bottom tab bar** (Online library / Local library / Slideshow / Daily / Settings / About). Toolbar buttons wrap, search and counts move to their own rows, cards flow into 2–3 columns, and touch targets get larger. The theme toggle moves to the header. On desktop the left sidebar stays (toggle it with `☰`).
- **Platform capability** (shown on the About page):
  - Windows / macOS / Linux: sets the system desktop wallpaper directly.
  - Android: the UI is touch/narrow adapted; setting the system wallpaper requires the mobile host to request `SET_WALLPAPER` and use `WallpaperManager`.
  - iOS / iPadOS: the OS forbids apps from changing the wallpaper; use **export to Photos**, then "Use as Wallpaper" manually.
- Note: packaging iOS / Android installers requires the respective mobile toolchains (Android NDK + cargo-mobile2 / Xcode).

## 17. Large libraries & adaptation screenshots

- **Paged lazy loading**: an album with more than 48 images shows one page first and a **Load more (N left)** button; click it to load the next page. Even folders with thousands of images never build all cards at once or blow up VRAM.
- **Multi-size adaptation screenshots**: run `wallpaper-rs --shots <out-dir>`; the app automatically renders every page (Library / Slideshow / Settings / About) at phone(390×844) / tablet(834×1112) / desktop(1440×900) sizes and saves PNGs for quick responsive review.
