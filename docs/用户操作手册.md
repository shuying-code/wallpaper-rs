# Wallpaper Studio 用户操作手册

本文介绍 Wallpaper Studio（`wallpaper-rs`）的安装、界面与各项功能的操作。

<p align="center">🌐 <a href="用户操作手册.md">简体中文</a> · <a href="用户操作手册.en.md">English</a></p>

---

## 1. 安装与启动

### 已编译版本（Windows）

1. 下载 `dist/wallpaper-rs-windows-x64.exe`。
2. 双击运行，无需安装，无需管理员权限。

### 从源码构建（全平台）

```bash
git clone https://github.com/shuying-code/wallpaper-rs.git
cd wallpaper-rs
cargo run --release
```

需要 Rust 1.75+。

---

## 2. 界面总览

窗口分为三部分：

- **顶部标题栏**：左侧品牌名与当前模式标签（轮播 / 已暂停），右侧显示当前壁纸文件名。
- **左侧导航**：壁纸库 / 轮播 / 设置 / 关于 四个分区。
- **主内容区**：随所选分区变化；底部状态栏显示载入数量与操作结果。

---

## 3. 壁纸库（固定壁纸）

1. 点击顶部「选择文件夹…」，选择一个包含图片的目录。
2. 若图片在子文件夹中，勾选「包含子文件夹」后点「重新扫描」。
3. 缩略图以网格显示；在「搜索」框按文件名过滤。
4. 点击任意缩略图，或缩略图下方的「设为壁纸」按钮，即可把该图设为桌面壁纸。
5. 当前壁纸会用蓝色描边并标注「● 当前」。

支持的图片格式：JPG / PNG / WebP / BMP / GIF / TIFF。

---

## 4. 轮播（自动更换）

进入「轮播」分区：

1. **模式**：选择「轮播」。
2. **开始 / 暂停**：点「开始」后按间隔自动更换；再次点击「暂停」停止。
3. **上一张 / 下一张**：手动切换（也可用键盘 `←` / `→`）。
4. **随机**：立即随机换一张。
5. **随机顺序**：勾选后，自动轮播按随机顺序进行。
6. **间隔**：拖动滑杆或点击预设（10秒 / 30秒 / 1分 / 5分 / 15分 / 30分 / 1时 / 6时 / 1天）。
7. 运行时进度条显示「距离下次更换」的剩余时间。

> 上方预览区会显示当前壁纸的大图预览。

---

## 5. 设置

- **显示方式**：填充 / 适应 / 拉伸 / 居中 / 平铺。Windows 写注册表桌面样式并立即生效；Linux 通过 GNOME `picture-options` 生效；macOS 使用系统默认缩放。
- **主题**：浅色 / 深色，切换后界面即时刷新。
- **扫描时包含子文件夹**：控制壁纸库是否递归扫描。
- **开机自动启动**：勾选后随系统登录自动运行。Windows 写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，macOS 写入 `~/Library/LaunchAgents`，Linux 写入 `~/.config/autostart`。
- **配置文件**：显示配置文件路径，可「打开配置目录」或「立即保存」。

---

## 6. 关于

显示版本号与功能清单。命令 `wallpaper-rs --version` 可打印版本，
`wallpaper-rs --selftest` 可执行配置与图片解码器自检。

---

## 7. 配置文件

所有设置自动保存为 JSON：

| 平台 | 路径 |
|---|---|
| Windows | `%APPDATA%\wallpaper-rs\config.json` |
| macOS | `~/Library/Application Support/wallpaper-rs/config.json` |
| Linux | `$XDG_CONFIG_HOME/wallpaper-rs/config.json`（默认 `~/.config/wallpaper-rs/config.json`） |

字段包括：`folder`、`recursive`、`mode`、`interval_secs`、`shuffle`、`fit`、`theme`、`last_path`、`running`、`search`。

## 9. 常见问题

- **设置壁纸没反应？** Windows 下请确认图片路径存在且有读取权限；Linux 需安装 GNOME（`gsettings`）或 `feh`；macOS 首次使用可能需在「系统设置 → 隐私与安全性 → 自动化」中允许控制 System Events。
- **缩略图显示「载入中…」？** 大图解码需要片刻，稍等即会显示；显示「无法预览」表示该文件无法解码。
- **界面中文显示为方框？** 程序已内嵌系统 CJK 字体加载逻辑，正常不会出现；若出现请确认系统存在中文字体。

---

## 10. 卸载

- Windows：删除 exe 文件即可；如需清除配置，删除 `%APPDATA%\wallpaper-rs` 目录。
- macOS / Linux：删除可执行文件，并删除上表中的配置目录。
