# Wallpaper Studio 用户操作手册

本文介绍 Wallpaper Studio（`wallpaper-rs`）的安装、界面与各项功能的操作。

<p align="center">🌐 <a href="用户操作手册.md">简体中文</a> · <a href="用户操作手册.en.md">English</a></p>

---

## 1. 安装与启动

### 已编译版本（Windows）

1. 下载 `dist/wallpaper-rs-windows-x64.exe`。
2. 双击运行，无需安装，无需管理员权限。

### 从源码构建（全平台）

```bash
git clone https://github.com/shuying-code/wallpaper-rs.git
cd wallpaper-rs
cargo run --release
```

需要 Rust 1.85+（Windows 电视直播依赖的 `wry` / `tao` 要求 1.85+）。

## 2. 界面总览

窗口分为三部分：

- **顶部标题栏**：最左侧 `☰` 按钮可隐藏 / 显示左侧导航栏；其后为品牌名与当前模式标签（轮播 / 已暂停），右侧显示当前壁纸文件名。
- **左侧导航**：一级菜单「壁纸 / 音乐 / 视频 / 硬件 / 智能感知」，选中后列出该分区的二级页（含各自的「设置」）；底部固定「通用设置 / 关于」（可用 `☰` 收起）。
- **主内容区**：随所选分区变化；底部状态栏显示载入数量与操作结果。

## 3. 本地壁纸库（固定壁纸）

1. 点击顶部「选择文件夹…」，选择一个包含图片（或动态壁纸视频，见下）的目录。
2. 若图片在子文件夹中，勾选「包含子文件夹」后点「重新扫描」。
3. 缩略图**按所在文件夹分组为相册**：每个相册标题前有 `▼ / ▶`，点击可单独展开 / 折叠；工具栏提供「全部展开 / 全部折叠」，并显示相册数量。相册默认按文件夹的修改时间由近到远排列（最近用过的文件夹排在最上面）。
4. 在「搜索」框按文件名过滤（自动隐藏无匹配的相册）。
5. 点击任意缩略图，或缩略图下方的「设为壁纸」按钮，即可把该图设为桌面壁纸；若为视频，按钮显示「设为动态壁纸」，点击后循环播放（Windows / macOS / Linux-X11 使用 mpv，Android 使用系统动态壁纸服务；见 4. 网上壁纸库的动态壁纸说明）。
6. 当前壁纸会用蓝色描边并标注「● 当前」。
7. 若扫描到无读取权限的目录，顶部会出现提示条：点「请求权限 / 重试」再次尝试（macOS 会弹出系统授权框），点「打开文件夹位置 / 打开授权设置」跳转到资源管理器或系统授权页面，由你确认授权；也可点「忽略」。

支持的图片格式：JPG / PNG / WebP / BMP / GIF / TIFF。

动态壁纸视频：MP4 / WebM / MKV / MOV / M4V / AVI / WMV / FLV 等。视频与图片一起显示在壁纸库中（缩略图位置显示 `▶ 动态壁纸`），同样可「加入轮播 / 移出轮播」，也可直接「设为动态壁纸」。Windows / macOS / Linux-X11 依赖 mpv；Android 由系统动态壁纸服务播放。手机竖屏播放横屏视频时会按比例完整显示并留黑边，以保证画面不被裁切或拉伸。

## 4. 网上壁纸库（多站点在线）

进入左侧导航的「网上壁纸库」分区，顶部可一键切换四个真实壁纸站点：

| 站点 | 域名 | 特点 |
|---|---|---|
| 微软必应每日壁纸 | `bing.ioliu.cn` | 4K 每日更新，可下载 3840×2160 原图 |
| 彼岸图网 | `pic.netbian.com` | 4K / 5K / 8K 高清 |
| MoeWalls | `moewalls.com` | 动态壁纸（MP4） |
| MotionBGs | `motionbgs.com` | 动态壁纸（MP4） |

操作步骤：

1. **切换来源**：点击站点按钮即可切换来源（微软必应每日壁纸 / 彼岸图网 / MoeWalls / MotionBGs）。
2. **关键词搜索**：在搜索框输入关键词（如「风景」「星空」），点「搜索」即可在该站搜索；点「返回分类」回到按分类浏览。
3. **按分类 / 标签浏览**：工具条下方点击分类项切换（各站点的分类 / 标签来自站点自身）。
4. **分页翻页**：工具条提供「‹ 上一页」「第 x / y 页」「下一页 ›」「本页 N 张」，可点「刷新」重新拉取当前页。
5. **预览与操作**：点击任意缩略图打开大图预览，预览区提供：
   - 「设为桌面壁纸」「设为锁屏」——下载原图后自动应用；
   - 「下载原图」——把原图保存到 `图片/网上壁纸库/<站点>`；
   - 「下载动态壁纸 MP4」（MoeWalls / MotionBGs 等动态站点）——把动态壁纸保存到同一目录；
   - 「设为动态壁纸」（MoeWalls / MotionBGs 等动态站点）——先下载 MP4，再循环播放；Windows / macOS / Linux-X11 铺到桌面图标层之下，Android 拉起系统动态壁纸预览并在确认后生效；
   - 「＋ 轮播(原视频)」（MoeWalls / MotionBGs 等动态站点）——把**原视频**加入轮播清单：轮播轮到该条目时会以动态壁纸（原视频）播放，而不是只轮播封面原图；已在清单中时显示「移出轮播(原视频)」；
   - 「关闭预览」。
   > 原图下载过程中会提示「原图下载中，完成后自动执行所选操作」。
   > 动态壁纸依赖 **mpv** 播放器：Windows 发行包**不内嵌 mpv**，会先在本机 PATH / 常见安装目录中查找；找不到时从上游官方发行版按需下载便携版到 `%LOCALAPPDATA%\wallpaper-rs\mpv-runtime`。macOS / Linux 需自行安装 mpv，也可用环境变量 `WALLPAPER_MPV` 指定 `mpv.exe` 路径。mpv 为第三方 GPL 组件，见随包 `THIRD-PARTY-NOTICES.md`。动态壁纸在 App 运行期间常驻，退出 App 会一并停止。
6. **收藏**：缩略图卡片角落空心 `☆` 点击变实心 `★` 即加入收藏；顶部「☆ 仅看收藏（N）」可在「仅看收藏 / 收藏中」之间切换，收藏中还可按标题筛选；收藏会持久化保存。
7. **清理缩略图缓存**：点「清理缩略图缓存」可释放纹理缓存，回收内存。

说明：本分区需联网访问对应站点；加载失败会显示「失败：…」并提供「重试」。切换来源 / 分类、搜索、翻页等浏览状态会自动记住，下次进入自动恢复。

## 5. 轮播（自动更换）

进入「轮播」分区：

1. **模式**：选择「轮播」。
2. **开始 / 暂停**：点「开始」后按间隔自动更换；再次点击「暂停」停止。
3. **上一张 / 下一张**：手动切换（也可用键盘 `←` / `→`）。
4. **随机**：立即随机换一张。
5. **随机顺序**：勾选后，自动轮播按随机顺序进行。
6. **间隔**：拖动滑杆或点击预设（10秒 / 30秒 / 1分 / 5分 / 15分 / 30分 / 1时 / 6时 / 1天）。
7. 运行时进度条显示「距离下次更换」的剩余时间。

> 上方预览区会显示当前壁纸的大图预览。

> **动态壁纸轮播**：轮播清单既可以是静态图片，也可以是动态壁纸视频。把含视频的文件夹载入「本地壁纸库」（或在线下载动态壁纸 MP4）并将其「加入轮播」后，轮播会在轮到时自动切换为动态壁纸（Windows / macOS / Linux-X11 使用 mpv）；轮到静态图片时会自动停止 mpv 宿主，避免动态画面盖住新壁纸。Android 的动态壁纸必须由用户在系统预览页确认，轮播会跳过视频项。视频缩略图显示 `▶ 动态壁纸`，预览区显示播放占位符。若当前系统未安装 mpv，视频项会提示「动态壁纸设置失败」并跳到下一项。

## 6. 设置（按一级菜单分开）

设置不再堆在一个页面里，而是跟着一级菜单走；每个分区的「设置」只显示本分区相关项。

- **壁纸设置**（壁纸 › 壁纸设置）：显示方式（填充 / 适应 / 拉伸 / 居中 / 平铺；Windows 写注册表桌面样式并立即生效，Linux 走 GNOME `picture-options`，macOS 用系统默认缩放）、扫描包含子文件夹、仅壁纸尺寸、自动每日换壁纸、获取后自动设为桌面、轮播随机顺序，以及「将当前静态壁纸设为静态锁屏」。
- **音乐设置 / 视频设置**（音乐 › 音乐设置、视频 › 视频设置）：各自的媒体文件夹（添加 / 移除 / 重新扫描）、各自独立的音量与列表循环（改音乐音量不会影响视频，反之亦然）。
- **硬件设置**（硬件 › 硬件设置）：华硕硬件总开关、采样间隔、Aura 写入前解除独占、跟随壁纸取色、风扇接管与滞回温度，并显示当前灯效 / 曲线摘要。设备清单、设备详情卡与灯效页还为每台 Aura 设备提供独立灯光开关：关闭为软件熄灭，只影响该设备在 Group S0 的 LED；没有独立 LED 节点的设备显示「不可独立控制」。
- **识别设置**（智能感知 › 识别设置）：智能感知总开关、摄像头设备、人回自动唤醒、预览打码、全屏豁免、陌生人快照；离开时长 / 锁定动作 / 解锁兜底请到「锁屏策略」页调整。**摄像头采集尚未接入（里程碑 M2），当前使用键鼠空闲检测；以上人脸相关开关仅保存配置，接入后才会生效。**「二次确认」会在倒计时结束后再等一段宽限（`grace_secs`）复检，仍判定离开才锁屏；「全屏豁免」在 Windows 下检测前台窗口是否整屏覆盖显示器，看视频 / 玩游戏 / 演示时暂停离开判定。
- **通用设置**（侧栏底部「通用设置」）：主题、开机自动启动、托盘与快捷键、问题上报与配置文件。

### 6.1 视频分区：电视直播（Windows）

进入「**视频 › 电视直播**」，可从内置目录选择央视 / 卫视频道：

1. **筛选频道**：顶部可在「全部 / 央视 / 卫视」间切换，或按频道名搜索；目录只展示 51 路免费频道，会员频道不会列入。
2. **选择并播放**：单击频道卡片选中，双击或点「▶ 播放」开始。第一次连接会启动隐藏的 WebView2 宿主，让央视频官方页面完成鉴权，通常需要数秒。
3. **播放方式**：可原生解码的清晰流会在**独立 mpv 窗口**中播放；官方标记为加密、返回非 HTTPS 地址或本机 mpv 不可用时，会自动改用同一宿主中的**官方播放器**。页面会如实显示「原生播放中 / 官方播放器中」并附回退原因。
4. **窗口与声音**：使用页面上的「全屏 / 窗口 / 音量 / 静音」控制当前播放器；关闭 mpv 或官方播放器窗口即结束本次直播，不会在后台继续播放。
5. **与本地媒体互斥**：开始电视直播会停止本地音乐 / 视频；开始本地媒体也会停止电视直播，避免两路声音重叠。

> **运行要求**：电视直播目前仅支持 Windows，需要 Microsoft Edge WebView2 Runtime（Windows 11 通常已内置，旧系统可安装微软官方 Evergreen Runtime）和 mpv。主界面与其它分区仍是原生 egui，不会启动 WebView2。
>
> **合规说明**：频道目录、官方页面鉴权脚本与播放规则适配自 MIT 许可的 ysp-live 项目。画面来自央视频官方网站；本应用不提供内容源、不代理视频、不绕过会员 / 付费 / DRM / 地区限制。频道可用性、清晰度和登录要求由官方决定，需保持联网。

**开机自动启动**：勾选后随系统登录自动运行。Windows 写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，macOS 写入 `~/Library/LaunchAgents`，Linux 写入 `~/.config/autostart`，Android 由 `BootReceiver` 在开机完成后恢复启动。Android 10+ 可能限制后台直接打开界面，此时会留下可点击的启动通知；部分厂商还需在系统「电池 / 自启动」设置中允许本应用后台运行。

**锁屏壁纸**：把当前壁纸同步设为系统锁屏。Windows 写 `HKLM\...\PersonalizationCSP`，需要管理员权限——点击后会自动弹出系统授权（UAC 用户账户控制），点「是」即完成，**无需手动以管理员身份运行**；Ubuntu / GNOME 通过 `gsettings` 设置锁屏 `picture-uri`；macOS 锁屏跟随系统壁纸。

## 8. 配置文件

所有设置自动保存为 JSON：

| 平台 | 路径 |
|---|---|
| Windows | `%APPDATA%\wallpaper-rs\config.json` |
| macOS | `~/Library/Application Support/wallpaper-rs/config.json` |
| Linux | `$XDG_CONFIG_HOME/wallpaper-rs/config.json`（默认 `~/.config/wallpaper-rs/config.json`） |

字段包括：`folder`、`recursive`、`mode`、`interval_secs`、`shuffle`、`fit`、`theme`、`last_path`、`running`、`search`，以及网上壁纸库的浏览状态 `web_source_key`、`web_category`、`web_query`、`web_search_active`、`web_only_fav`、`web_favorites`。

## 10. 常见问题

- **设置壁纸没反应？** Windows 下请确认图片路径存在且有读取权限；Linux 需安装 GNOME（`gsettings`）或 `feh`；macOS 首次使用可能需在「系统设置 → 隐私与安全性 → 自动化」中允许控制 System Events。
- **缩略图显示「载入中…」？** 大图解码需要片刻，稍等即会显示；显示「无法预览」表示该文件无法解码。
- **网上壁纸库加载失败？** 请确认网络可访问对应站点（部分站点需要可访问境外网络）；可点「重试」，或切换来源 / 分类后重试。
- **界面中文显示为方框？** 程序已内嵌系统 CJK 字体加载逻辑，正常不会出现；若出现请确认系统存在中文字体。

## 11. 卸载

- Windows：删除 exe 文件即可；如需清除配置，删除 `%APPDATA%\wallpaper-rs` 目录。
- macOS / Linux：删除可执行文件，并删除上表中的配置目录。

## 12. 关闭到系统托盘（图标常显）

点击窗口右上角「×」默认不会退出程序，而是把窗口隐藏到系统托盘，任务栏图标随之消失，轮播、在线每日壁纸等继续在后台运行：

- Windows：右下角通知区域。
- macOS：顶部菜单栏。
- Linux：桌面状态区 / AppIndicator。

为避免 Windows 11 把它收进「显示隐藏的图标」里，程序启动时会尽量把自身托盘图标固定为「始终显示」；若仍未显示，可在「通用设置 → 托盘与快捷键」点击「打开托盘设置（把图标设为始终显示）」，在系统设置里把它切到「显示」一次即可长期保留。

单击托盘图标可重新显示窗口；右键菜单提供「显示主界面 / 隐藏到托盘 / 退出 wallpaper-rs」。其中「退出 wallpaper-rs」是真正的退出：结束后台进程，并一并结束本机所有其它 wallpaper-rs 实例（例如自启 + 手动启动、重复双击 exe 打开的多份程序），确保不会残留后台轮播。

> 若不想关闭后继续在后台运行，可在「通用设置 → 托盘与快捷键」关闭「关闭时隐藏到托盘」，此时点击「×」将直接退出。

## 13. 全盘扫描

在「本地壁纸库」工具栏点击「全盘扫描」：程序会在后台扫描所有磁盘中的图片（自动跳过系统目录、缓存目录，并限量收集以避免长时间占用），完成后自动载入本地壁纸库。扫描在后台进行，界面不卡顿。

## 14. 托盘与全局快捷键

- **关闭时隐藏到托盘**：默认开启；关闭窗口后隐藏到通知区域（托盘图标常显），轮播与在线壁纸在后台继续运行。
- **全局快捷键**：默认 `Ctrl+Alt+W` 显示 / 隐藏窗口；若该组合被其它软件占用，会自动回退到 `Ctrl+Alt+Shift+W` 等，设置页会显示实际生效的快捷键。
- 也可在设置页点击「隐藏到托盘」立即收起窗口（不占任务栏），或点击「退出应用」彻底退出（同样会结束所有 wallpaper-rs 实例）。

## 15. 显示与兼容

「通用设置 → 显示与兼容」会显示检测到的显示器数量、主屏物理分辨率与当前主题。程序对高 DPI 缩放由系统自动适配；壁纸将应用到所有显示器。

## 16. 响应式界面与移动端（iOS / Android）

- **界面重新设计**：整体采用「冷调中性 + 靛蓝强调」（瓷白 / 近黑中性底色，彩色只用于在场 / 警告 / 危险等状态），浅色 / 深色主题一致。
- **窄屏 / 手机自动切换布局**：当窗口宽度小于约 820pt（或运行在手机 / 平板）时，左侧导航自动收起为**底部标签栏**（壁纸 / 音乐 / 视频 / 硬件 / 智能感知 + 通用设置）；进入一级菜单后用内容区顶部的二级页签切换该分区页面，包括各分区的「设置」。页签一行放不下时自动换行（例如壁纸分区的 5 个页签在 390px 下分两行显示），不依赖横向滑动。工具栏按钮自动换行、搜索与计数分行、图库卡片按 2–3 列自适应、触控目标加大；主题切换按钮移到标题栏右上角。桌面端保持左侧导航布局，可用 `☰` 手动收起。
- **平台与能力**：「关于」页显示当前平台与壁纸能力：
  - Windows / macOS / Linux：可直接设置系统桌面壁纸。
  - Android：界面已适配触控与窄屏；静态壁纸经 `WallpaperManager` 设置，视频壁纸由 `VideoWallpaperService` 播放，并按原始宽高比完整显示。
  - iOS / iPadOS：系统不允许 App 直接更改壁纸，移动端以浏览为主，请将图片「导出到相册」后在「照片」中手动「用作墙纸」。
- 说明：打包 iOS / Android 安装包需要对应的移动工具链（Android NDK + cargo-mobile2 / Xcode）。

## 17. 大图库与适配截图

- **大图库分页懒加载**：当某个相册图片较多（超过 48 张）时，只先显示一页，底部出现「加载更多（还有 N 张）」按钮，点击再加载下一页。这样即使单目录有几千张，也不会一次性构建所有卡片或爆显存。
- **多尺寸适配截图**：命令行运行 `wallpaper-rs --shots <输出目录>`，程序会自动在 手机(390×844) / 平板(834×1112) / 桌面(1440×900) 等尺寸下，逐页（图库 / 轮播 / 通用设置 / 关于，以及 5 个分区设置页）截图并保存为 PNG，方便快速核对界面适配效果。可用 `WP_SHOT_SIZES=desktop` 只截桌面尺寸。
