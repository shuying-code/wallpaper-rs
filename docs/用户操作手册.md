# Wallpaper Studio 用户操作手册

本文介绍 Wallpaper Studio（`wallpaper-rs`）的安装、界面与各项功能的操作。

<p align="center">🌐 <a href="用户操作手册.md">简体中文</a> · <a href="用户操作手册.en.md">English</a></p>

---

## 1. 安装与启动

### 已编译版本（Windows）

1. 下载 `dist/wallpaper-rs-windows-x64.exe`。
2. 双击运行，无需安装，无需管理员权限。

### 从源码构建（全平台）

```bash
git clone https://github.com/shuying-code/wallpaper-rs.git
cd wallpaper-rs
cargo run --release
```

需要 Rust 1.75+。

---

## 2. 界面总览

窗口分为三部分：

- **顶部标题栏**：最左侧 `☰` 按钮可隐藏 / 显示左侧导航栏；其后为品牌名与当前模式标签（轮播 / 已暂停），右侧显示当前壁纸文件名。
- **左侧导航**：网上壁纸库 / 本地壁纸库 / 轮播 / 每日壁纸 / 设置 / 关于 等分区（可用 `☰` 收起）。
- **主内容区**：随所选分区变化；底部状态栏显示载入数量与操作结果。

---

## 3. 本地壁纸库（固定壁纸）

1. 点击顶部「选择文件夹…」，选择一个包含图片的目录。
2. 若图片在子文件夹中，勾选「包含子文件夹」后点「重新扫描」。
3. 缩略图**按所在文件夹分组为相册**：每个相册标题前有 `▼ / ▶`，点击可单独展开 / 折叠；工具栏提供「全部展开 / 全部折叠」，并显示相册数量。相册默认按文件夹的修改时间由近到远排列（最近用过的文件夹排在最上面）。
4. 在「搜索」框按文件名过滤（自动隐藏无匹配的相册）。
5. 点击任意缩略图，或缩略图下方的「设为壁纸」按钮，即可把该图设为桌面壁纸。
6. 当前壁纸会用蓝色描边并标注「● 当前」。
7. 若扫描到无读取权限的目录，顶部会出现提示条：点「请求权限 / 重试」再次尝试（macOS 会弹出系统授权框），点「打开文件夹位置 / 打开授权设置」跳转到资源管理器或系统授权页面，由你确认授权；也可点「忽略」。

支持的图片格式：JPG / PNG / WebP / BMP / GIF / TIFF。

## 4. 网上壁纸库（多站点在线）

进入左侧导航的「网上壁纸库」分区，顶部可一键切换四个真实壁纸站点：

| 站点 | 域名 | 特点 |
|---|---|---|
| 微软必应每日壁纸 | `bing.ioliu.cn` | 4K 每日更新，可下载 3840×2160 原图 |
| 彼岸图网 | `pic.netbian.com` | 4K / 5K / 8K 高清 |
| MoeWalls | `moewalls.com` | 动态壁纸（MP4） |
| MotionBGs | `motionbgs.com` | 动态壁纸（MP4） |

操作步骤：

1. **切换来源**：点击站点按钮即可切换来源（微软必应每日壁纸 / 彼岸图网 / MoeWalls / MotionBGs）。
2. **关键词搜索**：在搜索框输入关键词（如「风景」「星空」），点「搜索」即可在该站搜索；点「返回分类」回到按分类浏览。
3. **按分类 / 标签浏览**：工具条下方点击分类项切换（各站点的分类 / 标签来自站点自身）。
4. **分页翻页**：工具条提供「‹ 上一页」「第 x / y 页」「下一页 ›」「本页 N 张」，可点「刷新」重新拉取当前页。
5. **预览与操作**：点击任意缩略图打开大图预览，预览区提供：
   - 「设为桌面壁纸」「设为锁屏」——下载原图后自动应用；
   - 「下载原图」——把原图保存到 `图片/网上壁纸库/<站点>`；
   - 「下载动态壁纸 MP4」（MoeWalls / MotionBGs 等动态站点）——把动态壁纸保存到同一目录；
   - 「关闭预览」。
   > 原图下载过程中会提示「原图下载中，完成后自动执行所选操作」。
6. **收藏**：缩略图卡片角落空心 `☆` 点击变实心 `★` 即加入收藏；顶部「☆ 仅看收藏（N）」可在「仅看收藏 / 收藏中」之间切换，收藏中还可按标题筛选；收藏会持久化保存。
7. **清理缩略图缓存**：点「清理缩略图缓存」可释放纹理缓存，回收内存。

说明：本分区需联网访问对应站点；加载失败会显示「失败：…」并提供「重试」。切换来源 / 分类、搜索、翻页等浏览状态会自动记住，下次进入自动恢复。

## 5. 轮播（自动更换）

进入「轮播」分区：

1. **模式**：选择「轮播」。
2. **开始 / 暂停**：点「开始」后按间隔自动更换；再次点击「暂停」停止。
3. **上一张 / 下一张**：手动切换（也可用键盘 `←` / `→`）。
4. **随机**：立即随机换一张。
5. **随机顺序**：勾选后，自动轮播按随机顺序进行。
6. **间隔**：拖动滑杆或点击预设（10秒 / 30秒 / 1分 / 5分 / 15分 / 30分 / 1时 / 6时 / 1天）。
7. 运行时进度条显示「距离下次更换」的剩余时间。

> 上方预览区会显示当前壁纸的大图预览。

## 6. 设置

- **显示方式**：填充 / 适应 / 拉伸 / 居中 / 平铺。Windows 写注册表桌面样式并立即生效；Linux 通过 GNOME `picture-options` 生效；macOS 使用系统默认缩放。
- **主题**：浅色 / 深色，切换后界面即时刷新。
- **扫描时包含子文件夹**：控制壁纸库是否递归扫描。
- **开机自动启动**：勾选后随系统登录自动运行。Windows 写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，macOS 写入 `~/Library/LaunchAgents`，Linux 写入 `~/.config/autostart`。
- **锁屏壁纸**：把当前壁纸同步设为系统锁屏。Windows 写 `HKLM\...\PersonalizationCSP`，需要管理员权限——点击后会自动弹出系统授权（UAC 用户账户控制），点「是」即完成，**无需手动以管理员身份运行**；Ubuntu / GNOME 通过 `gsettings` 设置锁屏 `picture-uri`；macOS 锁屏跟随系统壁纸。
- **配置文件**：显示配置文件路径，可「打开配置目录」或「立即保存」。

## 8. 配置文件

所有设置自动保存为 JSON：

| 平台 | 路径 |
|---|---|
| Windows | `%APPDATA%\wallpaper-rs\config.json` |
| macOS | `~/Library/Application Support/wallpaper-rs/config.json` |
| Linux | `$XDG_CONFIG_HOME/wallpaper-rs/config.json`（默认 `~/.config/wallpaper-rs/config.json`） |

字段包括：`folder`、`recursive`、`mode`、`interval_secs`、`shuffle`、`fit`、`theme`、`last_path`、`running`、`search`，以及网上壁纸库的浏览状态 `web_source_key`、`web_category`、`web_query`、`web_search_active`、`web_only_fav`、`web_favorites`。

## 10. 常见问题

- **设置壁纸没反应？** Windows 下请确认图片路径存在且有读取权限；Linux 需安装 GNOME（`gsettings`）或 `feh`；macOS 首次使用可能需在「系统设置 → 隐私与安全性 → 自动化」中允许控制 System Events。
- **缩略图显示「载入中…」？** 大图解码需要片刻，稍等即会显示；显示「无法预览」表示该文件无法解码。
- **网上壁纸库加载失败？** 请确认网络可访问对应站点（部分站点需要可访问境外网络）；可点「重试」，或切换来源 / 分类后重试。
- **界面中文显示为方框？** 程序已内嵌系统 CJK 字体加载逻辑，正常不会出现；若出现请确认系统存在中文字体。

## 11. 卸载

- Windows：删除 exe 文件即可；如需清除配置，删除 `%APPDATA%\wallpaper-rs` 目录。
- macOS / Linux：删除可执行文件，并删除上表中的配置目录。

## 12. 关闭到系统托盘（图标常显）

点击窗口右上角「×」默认不会退出程序，而是把窗口隐藏到系统托盘，任务栏图标随之消失，轮播、在线每日壁纸等继续在后台运行：

- Windows：右下角通知区域。
- macOS：顶部菜单栏。
- Linux：桌面状态区 / AppIndicator。

为避免 Windows 11 把它收进「显示隐藏的图标」里，程序启动时会尽量把自身托盘图标固定为「始终显示」；若仍未显示，可在「设置 → 托盘与快捷键」点击「打开托盘设置（把图标设为始终显示）」，在系统设置里把它切到「显示」一次即可长期保留。

单击托盘图标可重新显示窗口；右键菜单提供「显示主界面 / 隐藏到托盘 / 退出 wallpaper-rs」。其中「退出 wallpaper-rs」是真正的退出：结束后台进程，并一并结束本机所有其它 wallpaper-rs 实例（例如自启 + 手动启动、重复双击 exe 打开的多份程序），确保不会残留后台轮播。

> 若不想关闭后继续在后台运行，可在「设置 → 托盘与快捷键」关闭「关闭时隐藏到托盘」，此时点击「×」将直接退出。

## 13. 全盘扫描

在「本地壁纸库」工具栏点击「全盘扫描」：程序会在后台扫描所有磁盘中的图片（自动跳过系统目录、缓存目录，并限量收集以避免长时间占用），完成后自动载入本地壁纸库。扫描在后台进行，界面不卡顿。

## 14. 托盘与全局快捷键

- **关闭时隐藏到托盘**：默认开启；关闭窗口后隐藏到通知区域（托盘图标常显），轮播与在线壁纸在后台继续运行。
- **全局快捷键**：默认 `Ctrl+Alt+W` 显示 / 隐藏窗口；若该组合被其它软件占用，会自动回退到 `Ctrl+Alt+Shift+W` 等，设置页会显示实际生效的快捷键。
- 也可在设置页点击「隐藏到托盘」立即收起窗口（不占任务栏），或点击「退出应用」彻底退出（同样会结束所有 wallpaper-rs 实例）。

## 15. 显示与兼容

设置页「显示与兼容」会显示检测到的显示器数量、主屏物理分辨率与当前主题。程序对高 DPI 缩放由系统自动适配；壁纸将应用到所有显示器。

## 16. 响应式界面与移动端（iOS / Android）

- **界面重新设计**：整体采用暖色现代风格（米白背景 + 陶土橙主色 + 深青点缀），浅色 / 深色主题一致。
- **窄屏 / 手机自动切换布局**：当窗口宽度小于约 820pt（或运行在手机 / 平板）时，左侧导航自动收起为**底部标签栏**（网上壁纸库 / 本地壁纸库 / 轮播 / 每日 / 设置 / 关于）；工具栏按钮自动换行、搜索与计数分行、图库卡片按 2–3 列自适应、触控目标加大；主题切换按钮移到标题栏右上角。桌面端保持左侧导航布局，可用 `☰` 手动收起。
- **平台与能力**：「关于」页显示当前平台与壁纸能力：
  - Windows / macOS / Linux：可直接设置系统桌面壁纸。
  - Android：界面已适配触控与窄屏；设置系统壁纸需在移动端宿主中申请 `SET_WALLPAPER` 权限并通过 `WallpaperManager` 完成。
  - iOS / iPadOS：系统不允许 App 直接更改壁纸，移动端以浏览为主，请将图片「导出到相册」后在「照片」中手动「用作墙纸」。
- 说明：打包 iOS / Android 安装包需要对应的移动工具链（Android NDK + cargo-mobile2 / Xcode）。

## 17. 大图库与适配截图

- **大图库分页懒加载**：当某个相册图片较多（超过 48 张）时，只先显示一页，底部出现「加载更多（还有 N 张）」按钮，点击再加载下一页。这样即使单目录有几千张，也不会一次性构建所有卡片或爆显存。
- **多尺寸适配截图**：命令行运行 `wallpaper-rs --shots <输出目录>`，程序会自动在 手机(390×844) / 平板(834×1112) / 桌面(1440×900) 三种尺寸下，逐页（图库 / 轮播 / 设置 / 关于）截图并保存为 PNG，方便快速核对界面适配效果。
